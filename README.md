## Descripcion 
Este codigo hace uso de un árbol binario donde almacena y manipula lineas de textos. El usuario puede realizar 5 acciones: insertar o eliminar un caracter en cualquier posicion dada, puede concatenar otras frases, puede invertir la linea almacenada, puede imprimir en pantalla del dispositivo dicha linea y por ultimo la opcion de salir/parar el sistema.


## Características Técnicas 
* Lenguaje: C++
* Sistema operativo: Linux(Ubuntu 24.04)


## Como funciona el codigo
Al ejecutar el codigo se le pedira un string siendo la frase a insertar, posteriormente se le pedira insertar el tamaño maximo de cada nodo. Hecho eso le aparece el siguiente menu:

--- Menu ---
1. Insertar caracter
2. Eliminar caracter
3. Concatenar texto
4. Invertir
5. Imprimir texto actual
6. Salir

Para proseguir debe insertar el indice de la opcion de cual le gustaria acceder.
